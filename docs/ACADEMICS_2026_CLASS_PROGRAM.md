## Review before publication

- Confirm the printed class-program times and any actual timetable changes. The source's daily minute totals do not consistently match the individual rows, so the system uses row times, not the printed totals.
- Confirm HGP and enhancement handling with JCA before treating them as separate graded subjects. Phase 15 remains blocked by P-010.
- Confirm real teacher identities and assignments. The teacher-program pages provide names but do not identify matching accounts in this installation. Phase 14 never guesses or overwrites a teacher assignment.
- The Grade 6 TLE teacher surname differs between the daily program and paired teacher program; verify the staff record before assigning.
- Publishing the draft fills missing sections and subjects for the target school year. Existing enrollment, section, grade, teaching assignment, and finance history stays intact. The current local sample year contains other fictional sections; review those separately before production use.

For later school years, an Admin can create a new draft from the reusable Default curriculum option even if no version is saved, or copy a published version. The seeder and default option use the same configured class-program transcription, so the 73 grade-subject mappings and 20 section templates carry forward consistently. Timetable details must be reviewed for the new year; dates and teacher assignments remain separate year-specific facts.
